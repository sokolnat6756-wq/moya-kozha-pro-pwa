МОЯ КОЖА PRO — версия 1.1 (PWA для GitHub Pages)
==========================

ЧТО ЭТО
Русскоязычное локальное веб-приложение о базовых привычках бережного ухода за кожей.
Это НЕ медицинская диагностика и НЕ замена консультации дерматолога.

ФАЙЛЫ
- index.html — разметка пяти разделов.
- styles.css — оформление, мобильная адаптация, темы «Розовый кварц» и «Шампань».
- app.js — анкета, карточка, ритуалы, дневник, localStorage, экспорт и удаление.
- README.txt — эта инструкция.
- manifest.webmanifest — название, внешний вид и параметры установки PWA.
- sw.js — сохранение обязательных ресурсов и офлайн-навигация.
- icons/icon-192.png — настоящая PNG-иконка 192×192 для установки.
- icons/icon-512.png — настоящая PNG-иконка 512×512 для установки.

КАК ОТКРЫТЬ
1. Распакуйте ZIP целиком в отдельную папку.
2. Не переименовывайте файлы и не разносите их по разным папкам.
3. Для просмотра без установки можно открыть index.html прямо в браузере.
4. Для установки PWA и работы service worker нужны HTTPS (например, GitHub Pages)
   или localhost. При открытии через file:// установка PWA недоступна.
5. Для локальных записей пользуйтесь одним браузером на одном устройстве.
   Если file:// блокирует localStorage, откройте проект по localhost или HTTPS.

ЧТО РАБОТАЕТ
- 5 разделов: Главная, Анкета, Моя карточка, Уход, Дневник.
- Анкета: 7 вопросов по одному, прогресс, назад/далее, повторное прохождение.
- Один из 4 сценариев общих рекомендаций по главному пожеланию пользователя.
- Утренние 3 и вечерние 2 шага, отметки по выбранной дате.
- Дневник: 30 последовательных дней от первого открытия дневника,
  выбор ощущения, заметка до 280 символов, количество заполненных дней.
  Будущие дни недоступны до наступления даты.
- 2 темы оформления и адаптивная вёрстка.
- Локальное сохранение через localStorage без регистрации и отправки данных.
- «Экспорт данных JSON» — сохранение резервной копии (без импорта).
- «Удалить мои данные» — очистка с обязательным подтверждением.

ВАЖНО О ДАННЫХ
Данные находятся только в localStorage данного браузера на данном устройстве.
Очистка истории/данных сайта, приватный режим, смена браузера или устройства
могут привести к потере записей. При необходимости экспортируйте JSON.
Если сохранение заблокировано, приложение покажет предупреждение; записи
текущей вкладки могут работать, но после перезапуска исчезнуть.
Экспорт не загружает данные обратно в приложение: импорт не предусмотрен.

ПРОВЕРКА ВРУЧНУЮ — 7 ШАГОВ
1. Откройте index.html; проверьте главную и переходы в 5 разделов.
2. Переключите обе темы и убедитесь в читаемости на телефоне/компьютере.
3. Пройдите 7 вопросов; проверьте прогресс и кнопку «Назад».
4. Посмотрите карточку, перепройдите анкету с другим последним ответом.
5. В уходе поставьте галочки утром/вечером, выберите другую дату и вернитесь.
6. В дневнике выберите ощущение и напишите заметку; обновите страницу:
   отметки и тема должны сохраниться, если доступен localStorage.
7. Экспортируйте JSON, откройте его; затем удалите данные с подтверждением
   и проверьте, что карточка и дневник очищены.

ТЕХНИЧЕСКИЕ ЗАМЕТКИ
Сделано только на HTML, CSS и обычном JavaScript.
Все ссылки на файлы относительные: ./styles.css и ./app.js.
Нет библиотек, внешних шрифтов, CDN, API, регистрации или запросов
к внешним сервисам. Для первой загрузки и обновлений браузер запрашивает
только статические файлы с GitHub Pages.
Синхронизация, импорт JSON и Android APK не реализованы.
При file:// service worker не работает, а доступность localStorage зависит
от настроек браузера.

Ограничения безопасности: рекомендации общего характера; приложение не
определяет заболевания или тип кожи, не назначает лекарства, кислоты или
лечебные средства, не анализирует фотографии и не запрашивает медицинские
сведения. Если есть вопросы о состоянии кожи, обратитесь к дерматологу.


PWA / GITHUB PAGES — ПУБЛИКАЦИЯ В ПОДПАПКЕ
========================================
1. Создайте в GitHub репозиторий с именем moya-kozha-pro.
2. Загрузите в КОРЕНЬ репозитория все файлы и папку icons/,
   сохраняя написание имён и структуру. Не загружайте только ZIP.
3. В Settings → Pages выберите Deploy from a branch, ветку main,
   каталог /(root). Дождитесь сообщения GitHub Pages с опубликованным адресом.
4. Откройте https://ВАШ-ЛОГИН.github.io/moya-kozha-pro/ с подключённым интернетом.
   Ссылки на файлы относительные: ./styles.css, ./app.js, ./sw.js, ./icons/...
5. Дождитесь успешной установки service worker и сохранения всех ресурсов.
   На Android используйте пункт меню браузера «Установить приложение» или
   «Добавить на главный экран», на iPhone/iPad — Safari → «Поделиться» →
   «На экран Домой» (название пункта может отличаться по версии iOS).
6. Перед использованием офлайн завершите первоначальную загрузку с сетью.
   Протестируйте запуск и обновление страницы в авиарежиме на реальном телефоне.

В браузере Chrome можно посмотреть состояние на DevTools → Application →
Service Workers и Cache Storage. На iPhone проверяйте реальным запуском
с иконки, без сети. Установка зависит от браузера, версии ОС и настроек.

ДЛЯ ОБНОВЛЕНИЯ В СЛЕДУЮЩЕЙ ПУБЛИКАЦИИ
====================================
1. При любом изменении HTML/CSS/JS/иконок/манифеста измените в sw.js
   CACHE_NAME: например, moya-kozha-pro-pwa-v1 → moya-kozha-pro-pwa-v2.
2. Опубликуйте все изменённые файлы, убедившись, что ничего не пропущено.
3. При следующем открытии с интернетом браузер загрузит новую версию
   service worker, обновит кэш и удалит старый кэш приложения.
4. При необходимости закройте и снова откройте установленное приложение.
   Обновление может применяться не мгновенно; проверяйте вручную.

Сохранение localStorage в app.js осталось без изменений. Данные из
предыдущего file://-адреса не переносятся автоматически на GitHub Pages:
это разные адреса и отдельные хранилища браузера. Также у разных браузеров
и у приложения, добавленного на главный экран, хранилища могут различаться.
Экспорт JSON позволяет сохранить резервную копию, но импорт не предусмотрен.
Очистка данных сайта может удалить записи. SW-кэш хранит только статические
файлы приложения, а не ответы, заметки или отметки.
